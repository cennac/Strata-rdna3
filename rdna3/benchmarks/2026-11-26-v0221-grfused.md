# v0.2.21 GR fused read: inactive on this BF16 split profile (b505)

`STRATA_GR_FUSED=1` no longer breaks graph capture in upstream v0.2.21. However, its fused launch is conditional on both `s_down` and `s_up` scale arrays: the int8+FP32-scale `STRATA_HC_REQ8` representation. The tested profile uses BF16 projections. `generate.cpp` explicitly rejects HC_REQ8 on a layer split and retains BF16. The flag therefore leaves the same two-kernel RDNA read active here.

The live engine environment carried the flag, but raw graph dumps captured zero `rdna_gr_fused` nodes. All 26 raw and sampled/continuation probes still matched the adopted reference and forced rollbacks stayed 33/23. The run was stopped during the objective load when the inactive path was confirmed, preserving the SIGTERM and partial evidence. No scored throughput was collected and no speed gain is claimed. The original production configuration and binary were restored; no monitor faults occurred.

The fix may matter to a supported single-card HC_REQ8 profile. It does not establish a faster BF16 or dual-card fused read. Keep `STRATA_GR_FUSED` absent in the measured split template.
