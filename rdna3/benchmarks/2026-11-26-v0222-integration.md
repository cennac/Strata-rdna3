# Strata v0.2.22 RDNA3 migration — b509/b510 (2026-11-26)

The adopted dev/0.2.21 profile was merged into upstream v0.2.22 on `dev/0.2.22`. A fresh HIP gfx1100 build reports engine 0.1.69. This is a validated experimental migration; production and main remain unchanged.

Hardware and workload: two RX 7900 XTX, 10900T ES, 96 GB DDR4, CPU PCIe 3.0 x8 per card; GSQ-RCO IQ3_XXS, 26/22 layer split, two request slots, int8 KV with 32768 resident positions and 131072 maximum positions per request. This is a short-prompt measurement, not a 128K input measurement. The pinned controller, weights, expert-profile seed, ROCm 10.1, power caps and fans are unchanged.

## Throughput

Single means one request using both GPUs, taking engine decode timing. Dual means two simultaneous requests, total tokens divided by batch wall time including first-token wait. Three fresh loads (forward, reverse, forward), 1024 output tokens per request, no cache hits. Presence penalty 1.5, temperature 0 and seed 42. Stock and prior optimized columns reuse their independently recorded runs and are not paired comparisons with this migration.

All 18 scored requests reached 1024 tokens. Code dual varied notably across load order; the median is reported, not the peak. Nothing is attributed to a single kernel by these end-to-end figures.

## Compatibility

All 14 raw and 12 sampled/continuation probes exactly match the frozen adopted 0.1.66 RDNA GR reference. Forced rollback counts are unchanged at Chinese 33 / code 23. The six-case, 128-output objective screen has no new failures: arithmetic JSON and ASCII formatting pass; four reasoning/code questions reach the output cap, as in the reference. This is not a complete quality score or proof for every possible request.

The migrated profile includes penalty-aware solo pipelining, dual-request pipelined MTP, fixed-zero expert-PCIe graphs, SH stream, 12 CPU workers, the gfx1100 exact subset, EXPDEC and RDNA GR reads. Upstream fixes remain present. `STRATA_GFX11_DEFAULTS=0` keeps the upstream default batch stack from disabling the measured pipeline. `STRATA_GR_FUSED` remains absent until a separate paired test qualifies it.

## Reproduction and evidence

Build this revision with the same ROCm compiler and gfx1100 target using rdna3/build.py. Resolve the placeholders in rdna3/dual-xxs.template.json. During timing use a private copy of the same expert-profile seed, turn prompt and conversation caches off, and use rdna3/bench.py with its published prompts and 1024 tokens. These frozen validation/scoring runs use explicit cache budgets raw/sample=8624, objective=8012, scored=8013 to preserve measured residency; the general template leaves sizing automatic.

The sanitized JSON records source/binary/reference hashes, every load's throughput, first-token timing and resources. Raw model responses and machine-specific launch files stay in the local b510 artifact directory. The runtime was restored, its source config and binary remained unchanged, and the test port was closed after completion.
