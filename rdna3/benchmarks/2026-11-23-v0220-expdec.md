# STRATA_EXPDEC on the exact profile: Chinese lanes gain about 3%, reference parity holds

b472 paired the [b464 exact profile](2026-11-23-v0220-exact.md) against the same profile plus `STRATA_EXPDEC=1` on dual RX 7900 XTX (26/22 layer split, ROCm 10.1, Qwen3.8-Flash-Next GSQ-RCO IQ3_XXS). Both arms ran the same integrated 0.1.66 binary from `53b8629` with the fixed expert-profile seed and the phase-specific cache budgets. The switch is the only configuration difference. The candidate's `expdec_gu_kernel` appeared in both stages' verifier graphs (364 nodes on stage 0, 308 on stage 1); the control has none. The down projection keeps its default kernel on these tensor types. The switch comes from the gfx1100 exact table already present in v0.2.19.

## Quality

Both arms matched all 14 raw and 12 sampled probes of the frozen [0.1.65 reference](../reference-0.1.65.json), including seeded sampling, live-prefix continuation, true two-slot batching and forced rollbacks (35/21). The fixed-zero verifier graph was observed at both stages and penalty-aware pipelining was verified from traces. Both arms passed the six-case objective gate with no new failures; cases 19 and 23 were answered correctly, the other four were not.

## Paired result

Three alternating fresh-load pairs; pair 2 reversed the workload order. All 36 scored requests finished at 1,024 output tokens with caches off. Throughput is engine decode tok/s for one request and total tokens over batch wall time for two.

| Workload | Control tok/s | EXPDEC tok/s | Throughput | TTFT | Faster pairs |
|---|---:|---:|---:|---:|---:|
| Chinese single | 116.60 | 120.00 | +2.92% | +0.13% | 3/3 |
| Chinese dual | 166.10 | 171.99 | +3.55% | -0.54% | 3/3 |
| Code single | 156.00 | 157.10 | +0.71% | -0.69% | 2/3 |
| Code dual | 226.51 | 228.49 | +0.87% | -0.10% | 2/3 |

Chinese single and Chinese dual each improved in all three pairs with a median gain above 2%, which meets the predeclared adoption rule. No workload lost more than 2% of throughput or regressed more than 5% in TTFT. The code lanes moved by less than 1%; code dual was slower in pair 2 on both arms.

## Scope

Record as an opt-in development profile: the four exact overrides plus `STRATA_EXPDEC=1`, with `STRATA_GFX11_DEFAULTS=0` and the existing pins unchanged. The automatic-cache template is not qualified by this result and stays unchanged. TSUM, GDN split, long-prefill TOPK, the WMMA and parallel tables, and the RDNA capture fix were not tested here. Production restoration was verified after the window; no deployment or `main` change. Per-pair values and gate outcomes: [JSON](2026-11-23-v0220-expdec.json).
