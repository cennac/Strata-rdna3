# STRATA_GDN_SPLIT on the exact + EXPDEC profile: reference parity holds, throughput drops

b473 paired the [b472 profile](2026-11-23-v0220-expdec.md) (four exact overrides plus `STRATA_EXPDEC=1`) against the same profile plus `STRATA_GDN_SPLIT=1` on dual RX 7900 XTX (26/22 layer split, ROCm 10.1, Qwen3.8-Flash-Next GSQ-RCO IQ3_XXS). Same integrated 0.1.66 binary from `53b8629`, fixed expert-profile seed and cache budgets; the switch is the only difference. The candidate's graphs carry the split recurrence and state kernels on both stages (20 nodes on stage 0, 16 on stage 1); the control has none.

## Quality

Both arms matched all 14 raw and 12 sampled probes of the frozen [0.1.65 reference](../reference-0.1.65.json) with forced rollbacks 35/21, and passed the graph and penalty-path checks. The objective gate showed no new failures. The switch changes the recurrence's kernel layout and commit topology without changing the emitted tokens in these probes.

## Paired result

Three alternating fresh-load pairs; pair 2 reversed the workload order. All 36 scored requests finished at 1,024 output tokens with caches off.

| Workload | Control tok/s | GDN split tok/s | Throughput | TTFT | Faster pairs |
|---|---:|---:|---:|---:|---:|
| Chinese single | 118.50 | 118.90 | +0.34% | +0.99% | 1/3 |
| Chinese dual | 175.94 | 164.15 | -6.70% | +1.75% | 0/3 |
| Code single | 159.20 | 155.50 | -2.32% | +1.26% | 0/3 |
| Code dual | 227.88 | 222.33 | -2.43% | +1.66% | 1/3 |

No workload met the adoption rule. Chinese dual, code single and code dual lost more than 2% of median throughput, so the switch is rejected and the development profile stays at the b472 configuration. TTFT changes stayed within 1.8%. Production restoration was verified after the window; no deployment or `main` change. Per-pair values: [JSON](2026-11-23-v0220-gdnsplit.json).
