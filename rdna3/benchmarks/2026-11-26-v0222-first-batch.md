## 验证范围

每轮 48 条正式请求均完成 1024 token。26 组冻结 token ID、强制回滚次数 33/23 和六题客观筛查通过。这些冻结与客观探针固定专家驻留，计速才启用换入并验证日志。计速时的完整生成文本在不同加载间存在差异，对照也有这种波动。质量结论限于冻结探针及客观筛查，四题在 128 token 上限截断。本轮计时只覆盖短输入。各次吞吐、首字、配对结果和阶段耗时见[脱敏数据](2026-11-26-v0222-first-batch.json)。

## 复测条件

使用 0.2.22、Qwen 引擎 0.1.69、ROCm 10.1、两张 RX 7900 XTX 24GB、96GB DDR4、PCIe 3.0 ×8。双卡按 26/22 层拆分，固定零专家 PCIe 比例，启用 MTP 和 int8 KV，每路容量 131072。所有计分负载使用同一份 GSQ-RCO IQ3_XXS、同一专家画像种子，`--expert-cache 8013 --batch 2 --batch-groups 2 --adapt-every 1 --adapt-swaps 48`。提示与会话缓存均关闭。依次测中文 128 token 单路预热、代码双路、中文单路、中文双路、代码单路、代码双路。正式请求各生成 1024 token，贪婪、seed 42、presence penalty 1.5，使用短提示。

对照与候选在同一实验使用相同二进制，每组重启进程并复制原始专家画像。三对顺序为关/开、开/关、关/开。单路读取引擎生成速度，双路计算总输出 token 除以整批墙钟。表内速度是每组中位数，百分比取三对各自变化率的中位数。

从开发版模板启动待测服务，应用上述缓存和专家缓存参数。`STRATA_PIPE_ADAPT_EVERY` 未设置是对照，`auto` 或 `first` 是各自实验开关。刷新实验的两组计分均使用 `STRATA_P4_TIMING=1`。每次加载后运行一次公开负载脚本，使用独立试验端口、独立画像副本和输出文件名。

```sh
python3 rdna3/bench.py --url http://127.0.0.1:8101 \
  --model Qwen3.8-Flash-Next-IQ3_XXS --repeats 1 --first-code-dual \
  --output burst-01.json
```

公开脚本记录吞吐和首字，实验另采集双槽位同载、专家换入和阶段耗时日志。`strata batch (pipelined …)` 行给出实际刷新轮次与换入数。每组保留完整结果，检查实际输出长度和两路同时生成。
